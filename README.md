# Opala: história e paixão sobre rodas

Mini site sobre a história do Chevrolet Opala e os projetos de
restauração e preparação realizados por apaixonados pelo modelo.

## Objetivo

Projeto acadêmico para praticar HTML semântico, navegação entre
páginas, imagens, listas, iframe e formulário, utilizando Git
para versionamento e GitHub para entrega.

## Páginas

- index.html: apresentação do tema e principais características.
- sobre.html: história do Opala, restauração e preparação turbo e aspirada.
- contato.html: formulário com nome, e-mail, assunto, categoria e comentário.

## Tecnologias e ferramentas

- HTML5
- Visual Studio Code
- Git
- GitHub

## Como visualizar

Baixe ou clone o repositório e abra o arquivo index.html no navegador.
Use o menu para acessar as páginas Sobre e Contato.

O vídeo incorporado precisa de conexão com a internet.

## Formulário

O formulário é demonstrativo e não envia mensagens nem armazena
informações. Ao enviar, os campos aparecem na URL da página.
Utilize dados fictícios para testar.
